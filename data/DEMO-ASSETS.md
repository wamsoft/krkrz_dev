# デモ用資材リスト (準備依頼)

`data/ROADMAP.md` のデモを作るのに必要な資材の一覧。**資材が要らないデモから先に
実装する**ので、ここに挙げたものは揃った順に着手する。

---

## 共通ルール

- **ライセンス**: リポジトリに同梱して再配布するので、**自作 / CC0 / パブリック
  ドメイン**に限る。CC-BY 等の表示義務があるものは、出典と条件を一緒に教えてもらえれば
  `licenses/` へ表記を追加して対応する (既存のライセンス収集の仕組みに乗せる)。
- **容量**: Web デモ (krkrz_web) にも載るので軽いほど良い。目安は
  画像 〜1MB / 音声 〜2MB / 動画 〜10MB。長さより「機能が分かること」優先。
- **置き場**: 各デモが自己完結する規約なので `src/core/data/<demo>/assets/` に置く
  (こちらで配置する。ファイル名も下記のとおりに揃えてもらえると助かるが、
  違っていても中で吸収する)。
- **形式**:
  - 画像 = png / jpg (アルファが要るものは png)
  - 音声 = **ogg (Vorbis) / opus / wav**。ループ再生の区間情報は同名 `.sli` ファイル
  - 動画 = **webm (VP8/VP9)** が第一候補。mp4/wmv も可 (経路が別なので両方あると
    比較になる)。mpg (MPEG-1) も可

## 1. `sound` — サウンド総合 (最優先)

| # | ファイル | 仕様 | 用途 |
|---|---|---|---|
| 1-1 | `bgm_loop.ogg` (または .opus) | 30〜60 秒、**イントロ + ループ**構造 | 再生・停止・シーク・ループ |
| 1-2 | `bgm_loop.sli` | 1-1 のループ区間情報 | `labels` / `onLabel` のラベル通過表示 |
| 1-3 | `se_*.wav` × 3〜4 | 0.2〜1 秒の短い効果音 (クリック / 決定 / キャンセル / 警告など) | 多重再生・pan・volume2 |
| 1-4 | `gain_loud.opus` / `gain_quiet.opus` | **音量差が大きい同系統の 2 曲** | 曲別ゲイン (`setGainQueryCallback`) の効果を実聴 |
| 1-5 | `rg_tagged.opus` / `rg_untagged.opus` | **ReplayGain タグ有り / 無しの同一音源** | `-opus_rg` の ON/OFF 比較 |
| 1-6 | `voice_sample.ogg` | 3〜10 秒の**声もの** (歌 or セリフ) | PhaseVocoder の time / pitch を動かして効果が分かりやすいもの |

> 1-4 と 1-5 は「同じ音源の別バージョン」であることが重要。1-6 は声だとピッチ変更が
> 一番分かりやすい (楽器だけだと違いが伝わりにくい)。

- `webui` — WebServer + ブラウザ UI (HTML/JS はこちらで書く)
- `system_debug` — System 情報 / Debug / Scripts.eval / 例外ハンドラ
