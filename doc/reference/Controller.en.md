# Controller

The Controller class manages the **controller**. You cannot create objects of this class (the class itself is not accessible). Access its object through `Debug.controller`.

## Members

### Properties

- [visible](#visible)

### visible

Property \ Access: `r/w`

**Description**

Whether it is visible

Indicates whether the controller is visible. This property can also be set.

Set it to true to show the controller.
