# Clipboard

Clipboard クラスは OSの**クリップボード**にアクセスする機能を提供するクラスです。このクラスからオブジェクトを作成することはできません。

Windows ネイティブ ( WINVER ) ビルドと SDL3 ビルドの双方で利用できます
( SDL3 ビルドは 2026-08-16 に対応。それ以前は何もしない空実装でした )。
クリップボードを持たないプラットフォーム向けのビルドでは、書き込みは無視され
読み出しは常に void 、[hasFormat](#hasformat) は常に偽になります。

### asText

プロパティ \ アクセス: `r/w`

**解説**

テキスト形式

クリップボードに現在あるテキスト形式のデータを表します。値を書き込むこともできます。

値を読み出すと、現在クリップボードにあるテキスト形式のデータを得ることができます。クリップボードにテキスト形式のデータがない場合は、void が得られます。

値を書き込むと、クリップボードにテキスト形式のデータを格納することができます。

### hasFormat

メソッド

**引数**

| 引数 | 既定値 | 説明 |
| --- | --- | --- |
| `format` | `&nbsp;` | 存在を確認したいフォーマットを指定します。<br>cbfText ( = 1 ) を指定すると、クリップボード内にテキスト形式のデータが存在するかどうかを調べることができます。<br>cbfBitmap ( = 2 ) を指定すると、ビットマップ形式のデータが存在するかどうかを調べることができます ( Windows ネイティブ ( WINVER ) ビルドのみ )。 |

**戻り値**

指定されたフォーマットがクリップボード内に存在すれば真、存在しなければ偽

**解説**

指定されたフォーマットがクリップボード内に存在するか

指定された**フォーマット**がクリップボード内に存在するかどうかを調べることができます。

OS の提供するクリップボードは、同時に複数のフォーマットを持つことができるため、その中に特定のフォーマットがあるかどうかをこのメソッドで調べることができます。

### setAsBitmap

メソッド

**引数**

| 引数 | 既定値 | 説明 |
| --- | --- | --- |
| `layer` | `&nbsp;` | 画像を取り出すレイヤを指定します。 |

**戻り値**

格納できたら真、できなければ偽

**解説**

レイヤの画像をクリップボードへ置く

指定した**レイヤ**の画像を、ビットマップ形式でクリップボードへ格納します。

他のアプリケーションへ渡す都合で、α値は 255 に潰されます ( クリップボード上のビットマップのα値は、解釈するアプリケーションとしないアプリケーションが混在するためです )。透過を残したい場合は、あらかじめレイヤを合成してα値を無くしておいてください。

Windows ネイティブ ( WINVER ) ビルドでのみ動作します。他のビルドでは何もせず偽を返します。

### getAsBitmap

メソッド

**引数**

| 引数 | 既定値 | 説明 |
| --- | --- | --- |
| `layer` | `&nbsp;` | 画像を書き込むレイヤを指定します。 |

**戻り値**

読み込めたら真、読み込めなければ偽

**解説**

クリップボードの画像をレイヤへ取り込む

クリップボードにあるビットマップ形式のデータを、指定した**レイヤ**へ読み込みます。レイヤの画像サイズは読み込んだ画像に合わせて変更されます。クリップボード上の画像は不透明として扱い、α値は 255 で読み込みます ( レイヤ自身がα値を保持しない設定の場合は、レイヤ側の扱いに従います )。

Windows ネイティブ ( WINVER ) ビルドでのみ動作します。他のビルドでは何もせず偽を返します。
