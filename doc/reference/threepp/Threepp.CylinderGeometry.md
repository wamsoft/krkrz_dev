### CylinderGeometry

| --- | --- | --- |

| `radiusBottom` | `1` | 下面の半径 |
| `height` | `1` | 高さ |
| `radialSegments` | `16` | 周方向の分割数 |
| `heightSegments` | `1` | 高さ方向の分割数 |
| `openEnded` | `false` | 上下面を開けるか |
| `thetaStart` | `0` | 周方向の開始角度 |
