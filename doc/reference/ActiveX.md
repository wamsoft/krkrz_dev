# ActiveX

ActiveX を操作できるオブジェクトを生成します。
ActiveX が IDispatch で持つメソッドを直接呼び出すことができます。

継承元: [WIN32OLE](WIN32OLE.md)

### ActiveX

コンストラクタ

**引数**

| 引数 | 既定値 | 説明 |
| --- | --- | --- |
| `name` | `&nbsp;` | 識別名またはCLSID を文字列で指定。※WIN32OLE の指定とは CLSID の書式が違うので注意 CAxWindow::CreateControl の書式 |
| `win` | `null` | 指定するとそのウインドウの上に生成します。省略すると独立ウインドウになります。 |
| `left` | `0` | 表示座標 ウインドウ指定かつ省略の場合はウインドウのクライアント領域の左上 |
| `top` | `0` | 表示座標 ウインドウ指定かつ省略の場合はウインドウのクライアント領域の左上 |
| `width` | `100` | 表示サイズ   ウインドウ指定かつ省略の場合は親ウインドウのクライアント領域のサイズ |
| `height` | `100` | 表示サイズ  ウインドウ指定かつ省略の場合は親ウインドウのクライアント領域のサイズ |

**解説**

コンストラクタ

### setExternalUI

メソッド

**解説**

拡張UI指定

IEコンポーネントでのみ意味を持ちます。現在の版では、これ呼び出すことで
コンテキストメニューが抑制されます。

### onCreate

メソッド

**解説**

ウインドウ生成完了後に呼び出されるイベント

初期生成時やフルスクリーン処理などでウインドウが生成された後に呼ばれます
再構築後は、登録されていたイベントはすべて破棄される他、その他もろもろが
初期化されるので、このイベント内で必要なものを再設定する必要があります。
