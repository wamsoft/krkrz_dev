# リリーサー

吉里吉里Z の配布物は、[標準ツール](../../guide/Tools.md) で作ります。

- xp3 アーカイブの作成は [xp3 アーカイブツール (krkrxp3)](../../guide/Xp3Tool.md) で行います。吉里吉里2 の Releaser と同じ形式のアーカイブを作れます
- 配布用の実行可能ファイル (起動オプション・アイコン・バージョン情報の埋め込み、xp3 の結合、署名) は [リリーサ (krkrrelease)](../../guide/Releaser.md) で作ります (Windows 専用)
- 本体への xp3 アーカイブの結合は、吉里吉里Z でも使えます (Windows 版と、SDL 版の Windows / Linux)

## アイコンの差し替え
アイコンとバージョン情報は [リリーサ](../../guide/Releaser.md) で差し替えられます。
汎用のリソースエディタで差し替える場合は、xp3 の結合と署名より**前に**行ってください (後で差し替えると、結合した xp3 が失われ、署名も合わなくなります)。
