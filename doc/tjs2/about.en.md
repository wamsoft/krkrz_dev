# About TJS2

## About TJS2

TJS2 is an object-oriented scripting language designed to be embedded in applications. It also has features of non-object-oriented languages, so you can write code in whatever style is most convenient for you.

Its syntax is similar to JavaScript&trade; and Java&trade;, so it should be easy to learn.

## About This Manual

This manual describes TJS2 in terms of its syntax.

It also describes the classes built into TJS2 and their methods.
