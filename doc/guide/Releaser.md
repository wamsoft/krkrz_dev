# Releaser

## Releaser について

吉里吉里2 の Releaser (krkrrel.exe) は、次の 2 つの役割を持つツールでした。

- フォルダを xp3 アーカイブにまとめる
- 吉里吉里の実行可能ファイルに、プロジェクト (xp3) と起動オプション・アイコンを組み込んで、配布用の実行可能ファイルを作る

吉里吉里Z の [標準ツール](Tools.md) では、この 2 つを分けています。

- **xp3 アーカイブの作成** は [xp3 アーカイブツール (krkrxp3)](Xp3Tool.md) で行います。吉里吉里2 の Releaser と同じ形式のアーカイブを作り、Releaser のプロファイル (.rpf) も読み書きできます
- **配布用の実行可能ファイルの作成** (以下 «リリーサ») は準備中です

## 配布物の作り方 (リリーサが用意されるまで)

1. [xp3 アーカイブツール](Xp3Tool.md) でプロジェクトフォルダを `data.xp3` にまとめ、吉里吉里の実行可能ファイルと同じフォルダに置きます。吉里吉里は、実行可能ファイルと同じフォルダの `data.xp3` を自動的にプロジェクトとして読み込みます ([起動](Startup.md))
2. 実行可能ファイルの名前は自由に変えてかまいません。起動オプションは、実行可能ファイルと同じ名前の `.cf` ファイル (`game.exe` なら `game.cf`) に書いて同梱します ([コマンドラインオプション](CommandLine.md))
3. 必要なら [キー・署名ツール](SignTool.md) で、実行可能ファイル・xp3・プラグインに署名 (`.sig`) を付けます。エンドユーザ向けに [ファイル破損チェックツール](FileChkTool.md) を同梱できます
4. アイコンやバージョン情報を差し替える場合は、汎用のリソースエディタを使ってください (Windows 版)。署名は差し替えの**後で**行います

## リリーサで行う予定の処理

リリーサは、次の処理を行う予定です (Windows 版の実行可能ファイルが対象)。

- 実行可能ファイルをコピーして改名する
- リソースの書き換え: 埋め込みオプション、アイコン、バージョン情報
- セキュリティ設定 (`forcedataxp3` など) の書き換え
- xp3 アーカイブの結合 (選択式。ファイル 1 つで配りたい場合)
- 署名 (`.sig`) の作成

> **Note:**
> 吉里吉里2 の実行可能ファイルは、オプションや署名を書き込むための領域 (`XOPT_EMBED_AREA_` など) を持っていましたが、吉里吉里Z の実行可能ファイルにはありません。吉里吉里Z では、埋め込みオプションは Windows のリソースとして持ちます。このため、吉里吉里2 の Releaser で吉里吉里Z の実行可能ファイルにオプションを埋め込むことはできません。

## 実行可能ファイルへの xp3 の結合

吉里吉里Z は、実行可能ファイルの後ろに xp3 アーカイブが結合されていると、それをプロジェクトとして読み込みます (Windows 版と、SDL 版の Windows / Linux)。
探す順序は [起動](Startup.md) の «プロジェクトフォルダの決定順序» を参照してください。

結合は、実行可能ファイルの末尾に、16 バイト境界から xp3 アーカイブを付け足すだけです。
リリーサが用意されるまでは、次のようにして試せます (例は Windows のコマンドプロンプト)。

```
copy /b krkrz64.exe + data.xp3 game.exe
```

> **Note:**
> 実行可能ファイルのサイズが 16 の倍数でない場合は、間に 0 を詰めて 16 バイト境界に揃える必要があります。Windows 版の実行可能ファイルは通常 512 の倍数なので、そのままで揃います。
>
> 結合した後でリソースを書き換える (アイコンの差し替えなど) と、結合した xp3 が失われます。リソースの書き換えは結合の前に行ってください。
