# Color Constants

## Color Constants

You can use these constants wherever a color is specified. The actual colors of these values may change depending on the Windows settings.

```
`Scrollbar`clScrollBar           : Scroll bar color
`Background`clBackground          : Desktop background color
`ActiveCaption`clActiveCaption       : Title bar color of the active window
`InactiveCaption`clInactiveCaption     : Title bar color of inactive windows
`Menu`clMenu                : Menu background color
`Window`clWindow              : Window background color
`WindowFrame`clWindowFrame         : Window frame color
`MenuText`clMenuText            : Menu text color
`WindowText`clWindowText          : Text color inside windows
`CaptionText`clCaptionText         : Title bar text color of the active window
`ActiveBorder`clActiveBorder        : Border color of the active window
`InactiveBorder`clInactiveBorder      : Border color of inactive windows
`AppWorkspace`clAppWorkSpace        : Application workspace color
`Highlight`clHighlight           : Background color of selected text
`HighlightText`clHighlightText       : Color of selected text
`ButtonFace`clBtnFace             : Face color of 3D objects
`ButtonShadow`clBtnShadow           : Shadow color of 3D objects
`GrayText`clGrayText            : Color of grayed (disabled) text
`ButtonText`clBtnText             : Text color of 3D objects
`InactiveCaption`clInactiveCaptionText : Title bar text color of inactive windows
`ButtonHighlight`clBtnHighlight        : Button highlight color
`ThreeDDarkShadow`cl3DDkShadow          : Darker shadow of 3D objects
`ThreeDHighlight`cl3DLight             : Edge color of the lit face of 3D objects
`InfoText`clInfoText            : Tooltip text color
`InfoBackground`clInfoBk              : Tooltip background color
```

> **Note:**
> The color swatches above ( the labels such as `red` to the left of each color ) may not display correctly in some browsers.
