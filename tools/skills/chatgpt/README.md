# 吉里吉里Z / TJS2 開発ナレッジパック (ChatGPT 用)

krkrz_dev の Claude Code 用スキル (`tjs2` / `krkrz` / `elements` / `krkrz-repl` / `krkrz-webui`) と、
それが参照するリファレンス一式を、ChatGPT で使える形にまとめたものです。

| ファイル | 中身 |
|---|---|
| `instructions.md` | GPT / プロジェクトの「指示」欄に貼る文面 (8,000 文字以内) |
| `knowledge/` | ナレッジとしてアップロードするファイル (20 個以内) |
| `knowledge/00_INDEX.md` | 元のスキル内のパス → どのナレッジファイルに入っているかの対応表 |
| `skills/` | 元のスキルをそのまま自己完結形にしたもの (SKILL.md 形式。Codex など SKILL.md を読むツール用) |

## カスタム GPT にする

1. ChatGPT の「GPT を探す」→「作成する」→「構成」を開く
2. 「指示」に `instructions.md` の全文を貼る
3. 「知識」に `knowledge/` の中のファイルを全部アップロードする
4. 「機能」はコードインタープリターをオンにしておくと、ナレッジの全文検索がしやすくなります
   (ウェブ検索は任意。オンにすると吉里吉里2 時代の古い情報を拾うことがあります)

## プロジェクトで使う

1. ChatGPT でプロジェクトを作り、「指示」に `instructions.md` の全文を貼る
2. 「ファイル」に `knowledge/` の中のファイルを追加する
3. そのプロジェクトの中でチャットを始める

## Codex など SKILL.md を読むツールで使う

`skills/` の下のフォルダ (`tjs2/` など) を、そのツールのスキル置き場へフォルダごとコピーします。
ChatGPT 用に書き換えていない元の形なので、ファイルを読むツールを持つエージェントならそのまま使えます。

## 注意

- 中身は生成した時点の krkrz_dev のドキュメントです。更新されたら作り直して入れ替えてください
- ChatGPT はユーザーの PC で krkrz を起動できません。REPL での検証は、ChatGPT が示す手順を
  手元で実行し、結果を貼り付けて続ける使い方になります
